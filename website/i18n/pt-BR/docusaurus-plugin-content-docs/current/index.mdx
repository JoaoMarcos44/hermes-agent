O agente de IA autoaprimorável criado pela [Nous Research](https://nousresearch.com). O Hermes aprende com a experiência, cria e melhora habilidades durante o uso e mantém conhecimento entre sessões.

## Instalação

Para instalar facilmente os aplicativos de linha de comando e desktop no Windows ou macOS, [baixe o instalador do Hermes Desktop](https://hermes-agent.nousresearch.com/) e execute-o.

Sem o Hermes Desktop, no Linux / macOS / WSL2 / Android (Termux):

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

No Windows nativo (PowerShell):

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

Consulte o **[Guia de instalação](./getting-started/installation.md)** e o **[suporte a plataformas](./getting-started/platform-support.md)**.

## O que é o Hermes Agent?

O Hermes é um **agente autônomo** que combina ferramentas, memória persistente, habilidades reutilizáveis, automações e integrações de mensagens.
