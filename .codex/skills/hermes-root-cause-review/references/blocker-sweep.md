# Blocker Sweep Checklist

- [ ] Exact PR head and base recorded
- [ ] Current upstream main recorded
- [ ] Issue symptom independently validated
- [ ] Root cause separated from reporter hypothesis
- [ ] Related issues/PRs searched
- [ ] Competing heads inspected
- [ ] Canonical/superior/complementary status proven
- [ ] Positive regression added
- [ ] Negative sibling invariant added when predicate widened
- [ ] Symlink/path traversal checked when filesystem mutation changes
- [ ] Partial-write / rollback behavior checked
- [ ] Restart/shutdown/persistence checked when relevant
- [ ] Sweep 1 complete
- [ ] Sweep 2 complete
- [ ] Sweep 3 complete
- [ ] Reviews/threads re-fetched after final commit
- [ ] CI jobs actually ran before calling CI green
